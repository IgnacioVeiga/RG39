# Roadmap

## Próximas features
- Editor de parámetros de lanzamiento para juegos manuales existentes.
- Perfiles/grupos de juegos activos.
- Verificación de actualizaciones de la app.
- Integración y caché de carátulas.
- Temas personalizados.
- Mejor resolución de iconos nativos para juegos de Steam/Epic.

## Mejoras técnicas
- Más tests unitarios para escenarios de migración del repositorio.
- Introducir tests de integración para servicios específicos de Windows.
- Hooks opcionales de telemetría/diagnóstico para troubleshooting.
